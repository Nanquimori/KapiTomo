Privacy Policy

Last updated: September 1, 2026

KapiTomo is an author-run website created to publish free reading works, including novels, comics, and chapters organized for online reading. This policy explains how the site handles data during browsing.

Data collected directly

KapiTomo does not require registration, login, or personal data submission to read works published on the site. A user who voluntarily submits a Plugin Hub report provides a contact email and the report text as described below. The site does not sell user personal data.

Hosting technical data

The site is hosted on GitHub Pages. When users access pages, images, chapters, JSON files, or plugins, hosting services may process normal technical access data such as IP address, browser type, date, time, accessed URL, and diagnostic information needed to deliver the content.

How the site uses data

KapiTomo uses technical data only to:

  • Deliver pages, covers, chapters, and catalog files.
  • Allow online reading of free original works.
  • Provide catalogs and plugins used by Nyxovira and Nyxalira.
  • Publish and maintain the Plugin Hub catalog.
  • Keep the site accessible and fix technical problems.

Plugin Hub publication requests

The Plugin Hub lets developers submit public GitHub repositories for automatic technical validation and catalog publication. Publication, removal, and moderation requests are opened on GitHub and may include the plugin id, name, author, repository URL, icon URL, source site URL, version, tags, policy acceptance, and other manifest or moderation metadata. These requests are handled through GitHub's own systems and may be visible according to GitHub's settings.

Private Plugin Hub reports

The report form asks for a plugin ID, contact email, report reason, and confirmation that the reporter read the guidance and believes the provided information is true. The form also uses Cloudflare Turnstile to distinguish legitimate submissions from automated abuse. When the reporter selects Send, a KapiTomo Cloudflare Worker validates the form and the single-use Turnstile token and applies a short-term request limit using normal connection information such as the IP address. Cloudflare's privacy policy applies to that processing. An accepted report is stored privately in a Cloudflare D1 database available only to the KapiTomo account. The report and Turnstile token are not published as a GitHub issue, and the Turnstile token is not stored with the report. Report records expire after 90 days and are removed by a scheduled cleanup process. Each submission includes a plugin grouping key and a one-way fingerprint derived from the plugin ID and normalized report reason so duplicate reports can be recognized. After an accepted submission, the browser stores only that fingerprint, the plugin ID, and the submission time for up to 30 days to prevent an identical report from being resent from that browser; the report text and contact email are not stored there. KapiTomo uses the contact email and report text to verify the report, request clarification, communicate the result, prevent abuse, and keep a necessary review record. Reporters may request correction or deletion of their contact data by using the contact address below, subject to records that must be retained for security, legal, or abuse-prevention purposes.

Third-party plugins and content responsibility

Plugins published by community developers may connect to external sites that KapiTomo does not own or control. The plugin remains in its creator's public repository, while KapiTomo publishes its catalog entry. Reports do not change a listing automatically. KapiTomo may mark entries offline after technical checks, correct them, apply a documented preventive restriction after preliminary evidence of urgent risk is verified, restore corrected entries, or remove them when an authorized request or catalog-rule violation is confirmed.

Plugin health checks

KapiTomo may run automated checks against public plugin repositories, icon URLs, and source home pages to show whether a plugin is online or offline, and to remove entries whose public repository or plugin manifest disappears.

Original free content

Works published on KapiTomo are available for free reading. Nyxovira can prepare and organize compatible files, while Nyxalira provides the local reading experience.

External links

The site may contain links to external services such as YouTube, GitHub Pages, plugin files, or other project-related addresses. These services may have their own privacy policies and data practices.

Cookies and analytics

KapiTomo does not use its own login system, ads, or custom analytics. If a hosting service or external platform processes technical data, that processing follows that service's policies.
