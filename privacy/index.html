Politica de Privacidade

Ultima atualizacao: 25 de junho de 2026

O KapiTomo e um site autoral criado para publicar obras de leitura gratuitas, incluindo novels, quadrinhos e capitulos organizados para leitura online. Esta politica explica como o site lida com dados durante a navegacao.

Dados coletados diretamente

O KapiTomo nao exige cadastro, login ou envio de dados pessoais para ler as obras publicadas no site. O site tambem nao vende dados pessoais do usuario.

Dados tecnicos de hospedagem

O site e hospedado no GitHub Pages. Ao acessar paginas, imagens, capitulos, arquivos JSON ou plugins, servicos de hospedagem podem processar dados tecnicos normais de acesso, como endereco IP, tipo de navegador, data, hora, URL acessada e informacoes de diagnostico necessarias para entregar o conteudo.

Como o site usa dados

O KapiTomo usa dados tecnicos apenas para:

  • Entregar paginas, capas, capitulos e arquivos do catalogo.
  • Permitir leitura online das obras autorais gratuitas.
  • Disponibilizar catalogos e plugins usados pelos apps Nyxovira e Nyxalira.
  • Manter o site acessivel e corrigir problemas tecnicos.

Conteudo autoral e gratuito

As obras publicadas no KapiTomo sao disponibilizadas para leitura gratuita. Os apps Nyxovira e Nyxalira existem para ajudar leitores a acessar, organizar e ler obras, incluindo conteudo publicado no KapiTomo.

Links externos

O site pode conter links para servicos externos, como YouTube, GitHub Pages, arquivos de plugin ou outros enderecos relacionados ao projeto. Esses servicos podem ter suas proprias politicas de privacidade.

Cookies e analytics

O KapiTomo nao usa sistema proprio de login, anuncios ou analytics personalizado. Caso algum servico de hospedagem ou plataforma externa processe dados tecnicos, isso ocorre de acordo com as politicas desses servicos.
