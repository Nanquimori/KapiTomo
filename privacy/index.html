Privacy Policy

Last updated: September 10, 2026

What KapiTomo is

KapiTomo is a static website operated by Nanquimori to publish original works, public JSON APIs, and official Nyxovira plugins.

Data submitted to KapiTomo

The website does not provide accounts, login, or web forms that collect personal data. KapiTomo does not sell personal data.

Local browser preferences

The site may save the selected language and favorite official plugins in the browser's local storage. This information stays in that browser and is not sent to KapiTomo. It can be removed by clearing site data in the browser.

Hosting data

KapiTomo is hosted on GitHub Pages. GitHub may process normal technical access data, such as IP address, browser information, requested URL, date, time, and diagnostic records needed to deliver and protect the service. GitHub controls that processing under its own privacy terms.

External links

Pages may link to GitHub, Google Play, YouTube, or another external address. When a user opens an external service, that service may process data according to its own policy. KapiTomo does not control independently hosted catalogs or plugins connected manually in Nyxovira.

Cookies and analytics

KapiTomo does not operate its own account cookie, advertising system, or custom analytics service. Hosting providers and external services may use their own necessary technologies.

Contact

For privacy questions, contact nanquimori@gmail.com.

Política de Privacidade

O que é o KapiTomo

KapiTomo é um site estático mantido por Nanquimori para publicar obras originais, APIs JSON públicas e plugins oficiais do Nyxovira.

Dados enviados ao KapiTomo

O site não oferece contas, login nem formulários que coletem dados pessoais. O KapiTomo não vende dados pessoais.

Preferências locais do navegador

O site pode salvar no armazenamento local do navegador o idioma escolhido e os plugins oficiais marcados como favoritos. Essas informações permanecem no navegador e não são enviadas ao KapiTomo. Elas podem ser apagadas ao limpar os dados do site no navegador.

Dados da hospedagem

O KapiTomo é hospedado no GitHub Pages. O GitHub pode processar dados técnicos normais de acesso, como endereço IP, informações do navegador, URL solicitada, data, horário e registros de diagnóstico necessários para entregar e proteger o serviço. O GitHub controla esse tratamento conforme seus próprios termos de privacidade.

Links externos

As páginas podem apontar para GitHub, Google Play, YouTube ou outro endereço externo. Quando o usuário abre um serviço externo, esse serviço pode tratar dados conforme sua própria política. O KapiTomo não controla catálogos ou plugins hospedados independentemente e conectados manualmente no Nyxovira.

Cookies e análise

O KapiTomo não mantém cookie próprio de conta, sistema de anúncios nem serviço personalizado de análise. Provedores de hospedagem e serviços externos podem usar suas próprias tecnologias necessárias.

Contato

Para dúvidas sobre privacidade, escreva para nanquimori@gmail.com.
