Privacy Policy

Last updated: July 5, 2026

KapiTomo is an author-run website created to publish free reading works, including novels, comics, and chapters organized for online reading. This policy explains how the site handles data during browsing.

Data collected directly

KapiTomo does not require registration, login, or personal data submission to read works published on the site. The site also does not sell user personal data.

Hosting technical data

The site is hosted on GitHub Pages. When users access pages, images, chapters, JSON files, or plugins, hosting services may process normal technical access data such as IP address, browser type, date, time, accessed URL, and diagnostic information needed to deliver the content.

How the site uses data

KapiTomo uses technical data only to:

  • Deliver pages, covers, chapters, and catalog files.
  • Allow online reading of free original works.
  • Provide catalogs and plugins used by Nyxovira and Nyxalira.
  • Publish and maintain the Plugin Hub catalog.
  • Keep the site accessible and fix technical problems.

Plugin Hub publication requests

The Plugin Hub lets developers submit public GitHub repositories for review. Publication and removal requests are opened on GitHub and may include the plugin id, name, author, repository URL, icon URL, source site URL, version, tags, and other manifest metadata. These requests are handled through GitHub's own systems and may be visible according to GitHub's settings.

Third-party plugins and content responsibility

Plugins published by third parties or community developers may point to external sites that KapiTomo does not own or control. Plugin creators and source sites are responsible for their own code, metadata, content, page availability, download behavior, permissions, and legal rights. KapiTomo publishes only catalog entries and may remove entries that are broken, misleading, unauthorized, or reported by an affected party.

Plugin health checks

KapiTomo may run automated checks against public plugin repositories, icon URLs, and source home pages to show whether a plugin is online or offline, and to remove entries whose public repository or plugin manifest disappears.

Original free content

Works published on KapiTomo are available for free reading. Nyxovira and Nyxalira help readers access, organize, and read works, including content published on KapiTomo.

External links

The site may contain links to external services such as YouTube, GitHub Pages, plugin files, or other project-related addresses. These services may have their own privacy policies and data practices.

Cookies and analytics

KapiTomo does not use its own login system, ads, or custom analytics. If a hosting service or external platform processes technical data, that processing follows that service's policies.

Contact

For questions about this Privacy Policy, contact nanquimori@gmail.com.

KapiTomo is an official space for publishing and reading free original works.
