Política de Privacidade

Última atualização: 25 de junho de 2026

O KapiTomo é um site autoral criado para publicar obras de leitura gratuitas, incluindo novels, quadrinhos e capítulos organizados para leitura online. Esta política explica como o site lida com dados durante a navegação.

Dados coletados diretamente

O KapiTomo não exige cadastro, login ou envio de dados pessoais para ler as obras publicadas no site. O site também não vende dados pessoais do usuário.

Dados técnicos de hospedagem

O site é hospedado no GitHub Pages. Ao acessar páginas, imagens, capítulos, arquivos JSON ou plugins, serviços de hospedagem podem processar dados técnicos normais de acesso, como endereco IP, tipo de navegador, data, hora, URL acessada e informações de diagnóstico necessárias para entregar o conteúdo.

Como o site usa dados

O KapiTomo usa dados técnicos apenas para:

  • Entregar páginas, capas, capítulos e arquivos do catálogo.
  • Permitir leitura online das obras autorais gratuitas.
  • Disponibilizar catálogos e plugins usados pelos apps Nyxovira e Nyxalira.
  • Manter o site acessível e corrigir problemas técnicos.

Conteúdo autoral e gratuito

As obras publicadas no KapiTomo são disponibilizadas para leitura gratuita. Os apps Nyxovira e Nyxalira existem para ajudar leitores a acessar, organizar e ler obras, incluindo conteúdo publicado no KapiTomo.

Links externos

O site pode conter links para serviços externos, como YouTube, GitHub Pages, arquivos de plugin ou outros endereços relacionados ao projeto. Esses serviços podem ter suas próprias políticas de privacidade.

Cookies e analytics

O KapiTomo não usa sistema próprio de login, anúncios ou analytics personalizado. Caso algum serviço de hospedagem ou plataforma externa processe dados técnicos, isso ocorre de acordo com as políticas desses serviços.
