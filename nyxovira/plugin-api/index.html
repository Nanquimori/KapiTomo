Conecte fontes de leitura ao app

Uma referencia para criar addons que adaptam sites de novels ou quadrinhos ao Nyxovira: abrir a obra, mapear capitulos, baixar texto estruturado ou paginas de imagem. O KapiTomo aparece aqui apenas como exemplo completo.

01O addon abre uma fonte no navegador interno.
02O script identifica a obra aberta e instala o plano de capitulos.
03O engine baixa paragraphs para novel ou pages para quadrinho.

module.files

Arquivos do addon

Um addon tem um manifesto e um script executado dentro da pagina aberta no navegador do app.

ArquivoFuncao
plugin.jsonDefine nome, versao, dominio, pagina inicial, icone e parser da fonte.
browser/download_target.jsIdentifica a obra aberta e monta o plano de capitulos quando os dados ja existem na pagina.
Estrutura esperada: coloque os dois arquivos dentro de uma pasta com o id da fonte, por exemplo minha-fonte/plugin.json e minha-fonte/browser/download_target.js.
plugin.json

Manifesto da fonte

Use o manifesto para registrar a fonte e configurar como o Nyxovira deve reconhecer URLs dela.

plugin.jsonBaixar exemplo
{
  "schema_version": 1,
  "id": "minha-fonte",
  "name": "Minha Fonte",
  "version": "1.0.0",
  "match": {
    "hosts": ["example.com"]
  },
  "browser": {
    "home_url": "https://example.com/",
    "icon_url": "https://example.com/icon.png",
    "icon_mode": "pinned",
    "short_label": "Fonte",
    "download_target_script_file": "browser/download_target.js"
  },
  "parser": {
    "adapter": "html_series",
    "base_url": "https://example.com",
    "static_works_script": "https://example.com/data/works.js",
    "series_path_prefix": "manga",
    "chapter_path_prefix": "chapter"
  }
}
CampoUso
idIdentificador fixo do addon. Use letras minusculas, numeros e hifen.
versionAumente sempre que publicar uma correcao.
match.hostsDominios aceitos por este addon.
browser.home_urlPagina inicial aberta dentro do app.
parser.adapterUse html_series para site HTML, indice publico ou arquivo JS com obras.
routes.map

Rotas e campos da fonte

Cada fonte tem nomes proprios. O addon traduz esses nomes para o formato que o Nyxovira entende.

mapa manual
var addon = {
  siteBaseUrl: "https://example.com",
  sourceVariable: "SOURCE_WORKS",
  sourceRoutes: {
    work: "obra",
    read: "ler"
  },
  nyxoviraRoutes: {
    series: "manga",
    chapter: "chapter"
  },
  fields: {
    workId: "id",
    workTitle: "title",
    workSummary: "description",
    workCover: "cover",
    workChapters: "chapters",
    chapterParagraphs: "paragraphs",
    chapterPages: "pages",
    chapterImages: "images",
    imageSource: "src"
  }
};

browser.js

download_target.js

Este script roda quando o usuario toca em baixar. Ele retorna a URL da obra e pode instalar o plano de capitulos imediatamente.

Quando usar chapterPlan: se a pagina ou um arquivo JS publico ja tem a lista de capitulos, preencha window.__nyxoviraChapterPlan. Assim o app abre a selecao sem procurar capitulos no HTML.
download_target.js resumidoBaixar exemplo completo
(function () {
  var workId = currentWorkId();
  var work = workById(workId);

  if (!work) {
    return workUrl(workId);
  }

  window.__nyxoviraChapterPlan = JSON.stringify({
    title: work.title,
    summary: work.description,
    canonicalUrl: workUrl(work.id),
    coverUrl: work.cover,
    chapters: work.chapters.map(toChapter)
  });

  return workUrl(work.id);
})()

Checklist de publicacao

Antes de publicar um addon, valide o caminho inteiro de leitura e download.

VersaoAumente plugin.json.version e gere um novo zip do addon.
NavegadorTeste a home, uma pagina de obra e o botao de baixar.
PlanoConfirme title, summary, coverUrl e capitulos.
NovelConfirme que paragraphs tem varios itens separados.
QuadrinhoConfirme que pages tem URLs diretas de imagem.
CatalogoAtualize o sha256 do pacote no catalogo de plugins.
