Create source addons for Nyxovira

A source addon teaches Nyxovira how to open a reading site, detect an open work, show chapters immediately, and prepare selected chapters for offline download.

1Create plugin.json and browser/download_target.js.
2Map the source routes and fields manually inside the addon.
3Publish the repository and submit it through the Plugin Hub.

Addon files

Place the manifest and browser script inside one folder named after the source id.

my-source/
|-- plugin.json
`-- browser/
    `-- download_target.js
FilePurpose
plugin.jsonDefines the addon id, version, host, browser entry, icon, and parser.
browser/download_target.jsRuns inside the open page and builds the work download plan.

plugin.json

The manifest describes the source and tells Nyxovira which browser script to run.

{
  "schema_version": 1,
  "id": "my-source",
  "name": "My Source",
  "version": "1.0.0",
  "match": { "hosts": ["example.com"] },
  "browser": {
    "home_url": "https://example.com/",
    "icon_url": "https://example.com/icon.png",
    "icon_mode": "pinned",
    "short_label": "Source",
    "download_target_script_file": "browser/download_target.js"
  },
  "parser": {
    "adapter": "html_series",
    "base_url": "https://example.com"
  }
}

Manual mapping

Keep language and site-specific names inside the addon. The app receives one consistent Nyxovira format.

var addon = {
  siteBaseUrl: "https://example.com",
  sourceRoutes: { work: "work", read: "read" },
  nyxoviraRoutes: { series: "manga", chapter: "chapter" },
  fields: {
    workId: "id",
    workTitle: "title",
    workSummary: "description",
    workCover: "cover",
    workChapters: "chapters",
    chapterParagraphs: "paragraphs",
    chapterPages: "pages",
    imageSource: "src"
  }
};

Instant chapter list

When the user taps download, set window.__nyxoviraChapterPlan immediately and return the canonical work URL.

window.__nyxoviraChapterPlan = JSON.stringify({
  title: "Work title",
  summary: "Short summary",
  canonicalUrl: "https://example.com/manga/work/",
  coverUrl: "https://example.com/cover.png",
  chapters: [
    {
      id: "chapter-1",
      number: "1",
      title: "Chapter 1",
      contentType: "novel",
      paragraphs: ["First paragraph.", "Second paragraph."]
    }
  ]
});

return "https://example.com/manga/work/";

Prepare after selection

For large comics or APIs, keep the first plan lightweight. Load page URLs only after the user confirms selected chapters.

window.__nyxoviraPrepareDownloadPlan = function (context) {
  var selectedIds = context.selectedChapterIds || [];
  var plan = context.chapterPlan;

  plan.chapters.forEach(function (chapter) {
    if (selectedIds.length && selectedIds.indexOf(chapter.id) < 0) return;
    var payload = getJson(chapter.chapterDataPath);
    chapter.pages = payload.pages.map(function (page) {
      return page.imageUrl;
    });
    delete chapter.chapterDataPath;
  });

  window.__nyxoviraChapterPlan = JSON.stringify(plan);
  return plan;
};

Publishing

The Plugin Hub installs addons from public GitHub repositories. The repository is the addon source.

{
  "id": "my-source",
  "name": "My Source",
  "author": "Author",
  "version": "1.0.0",
  "description": "Source plugin for Nyxovira.",
  "site_url": "https://example.com/",
  "homepage": "https://example.com/",
  "icon_url": "https://example.com/icon.png",
  "repository_url": "https://github.com/user/my-source",
  "repository_ref": "main",
  "plugin_path": ".",
  "tags": ["portugues", "manga", "novel"]
}

Keep plugin.json and browser/download_target.js in the repository.

Open the Plugin Hub and paste the GitHub repository URL.

Confirm the GitHub request. Automation validates the repository and updates the catalog.
