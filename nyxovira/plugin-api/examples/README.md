# Sanitized examples

These examples use the reserved host `source.invalid`; they describe complete plugin shapes without naming or contacting a third-party reading site. Replace every placeholder only after mapping the source you are authorized to use.

- `simple-html`: browser script reads work and chapter data from rendered HTML.
- `json-api`: browser script calls a documented JSON API.
- `novel`: complete paragraph chapter plan.
- `manga`: complete image-page chapter plan with request headers.
- `encrypted-api`: browser discovery plus mandatory native parser configuration for a protected response.

An example is a template, not proof that a real source works. Run the official tester and the in-app diagnostic against a real work and chapter before reporting success.
