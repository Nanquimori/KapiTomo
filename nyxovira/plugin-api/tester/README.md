# Laboratório Web de Plugins Nyxovira

Acesse o laboratório publicado em:

<https://nanquimori.github.io/KapiTomo/nyxovira/plugin-api/tester/>

Envie o ZIP do plugin e informe a URL de uma obra real. O serviço hospedado escolhe o primeiro capítulo automaticamente e apresenta o diagnóstico na própria página. Não é necessário instalar programas, executar comandos, usar APK, ADB ou emulador.

O resultado válido contém:

- `PLUGIN_VALID`;
- nenhuma etapa `FAIL`;
- `temporaryDataReleased: true`;
- `stored: false`.

O serviço não possui banco de dados nem armazenamento de objetos. O ZIP, a navegação e o conteúdo coletado existem somente durante a requisição e são descartados ao final.
