Acesso

Entrar com GitHub

Entre no GitHub para publicar ou remover plugins. O Hub nao recebe email nem senha; o GitHub confirma a conta quando voce envia o pedido.

Publicar

Publique um addon pronto

Cole o repositorio GitHub que ja tem plugin.json. O Hub le o manifesto, procura uma Release .zip e abre um pedido de publicacao na sua conta.

Remover

Remova uma publicacao

Informe o plugin publicado e abra um pedido de remocao. A solicitacao fica registrada na sua conta GitHub.

Fluxo

Como entrar no catalogo

Empacote o addon

Crie um zip limpo com manifesto e script da fonte.

Publique no GitHub

Use Releases ou Pages da sua propria conta. O arquivo nao precisa ficar armazenado no KapiTomo.

Adicione ao catalogo

Use o botao de publicacao gerado pelo Hub. Ele abre um pedido no GitHub com a entrada pronta para entrar no catalogo publico.
