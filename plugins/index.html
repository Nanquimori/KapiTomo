Use sua conta GitHub

Hospede o pacote .zip no GitHub Releases, GitHub Pages ou outro servidor publico do autor. O KapiTomo so le o catalog.json e usa o link em package_url para instalar direto no app.

Como entrar no catalogo

Empacote o addon

Crie um zip limpo com manifesto e script da fonte.

Publique no GitHub

Use Releases ou Pages da sua propria conta. O arquivo nao precisa ficar armazenado no KapiTomo.

Adicione ao catalogo

Inclua a entrada no plugins/catalog.json. O Hub mostra nome, autor, versao, descricao e instala pelo link externo do pacote.
