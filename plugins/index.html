Plugin Hub

A public catalog for installing source plugins in Nyxovira. The app reads this catalog, downloads the plugin repository, and installs it without opening an external browser.

Publish

Publish a ready addon

Paste the GitHub repository that already contains plugin.json. The Hub reads the manifest and opens a GitHub request; after confirmation, automation validates the repository and publishes it to the catalog.

Remove

Remove a publication

Enter the published plugin and confirm the GitHub request. Automation validates it, removes it from the catalog, and posts the result.

Flow

How to join the catalog

Prepare the addon

Keep the manifest and source script organized in the repository.

Publish on GitHub

Use your own account. The addon stays in your repository, and KapiTomo publishes only the catalog entry.

Add it to the catalog

Use the publication button and confirm on GitHub. The automation updates the catalog and closes the request when it finishes.
