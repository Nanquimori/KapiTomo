Publicar

Use sua conta GitHub

Hospede o pacote .zip do plugin no seu GitHub Releases, GitHub Pages ou outro servidor publico. O zip deve conter plugin.json na raiz e browser/download_target.js.

{
  "id": "minha-fonte",
  "name": "Minha Fonte",
  "package_url": "https://github.com/usuario/repo/releases/download/v1/minha-fonte.zip",
  "sha256": "..."
}

Como entrar no catalogo

Empacote o addon

Crie um zip limpo com manifesto e script da fonte.

Publique no GitHub

Use Releases ou Pages da sua propria conta como hospedagem do arquivo.

Adicione ao catalogo

Inclua a entrada no plugins/catalog.json. Depois disso, o plugin aparece no app em Plugins online.
