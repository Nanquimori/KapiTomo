Publicar

Publique um addon pronto

Cole o repositorio GitHub que ja tem plugin.json. O Hub le o manifesto, procura uma Release .zip e cria uma solicitacao no GitHub; ao confirmar, o robo valida e publica no catalogo.

Remover

Remova uma publicacao

Informe o plugin publicado e confirme a solicitacao no GitHub. O robo valida, remove do catalogo e comenta o resultado.

Fluxo

Como entrar no catalogo

Empacote o addon

Crie um zip limpo com manifesto e script da fonte.

Publique no GitHub

Use Releases ou Pages da sua propria conta. O arquivo nao precisa ficar armazenado no KapiTomo.

Adicione ao catalogo

Use o botao Solicitar publicacao e confirme no GitHub. A Action atualiza o catalogo e fecha a solicitacao quando terminar.
